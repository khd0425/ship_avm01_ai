# avm6 dataset (phase-1 classes)

Built by `ai/prepare_dataset.py` from **COCO 2017** (person -> `person`, boat -> `small_vessel`):
train 2,385 images / val 261 images. Classes `bollard, fender, quay_edge, buoy` have no data yet.

Licences: COCO annotations are CC BY 4.0 and the images come from Flickr under their individual
licences (some are non-commercial) — **verify before any redistribution or delivery**. Keep this
repository private. See `docs/ai_dataset_plan.md`.
